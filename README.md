# TechShop — Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## О проекте
Учебный интернет-магазин электроники TechShop. В этой версии адаптивность реализована самостоятельно на CSS, без Bootstrap, чтобы соответствовать методическим указаниям КР №3.

## Страницы
- `index.html` — главная, преимущества и популярные товары.
- `catalog.html` — каталог с поиском и фильтрацией по категориям.
- `product.html` — карточка товара и таблица характеристик.
- `order.html` — форма заявки.
- `contacts.html` — контакты и форма обратной связи.

## Структура
- `css/style.css` — базовые стили.
- `css/responsive.css` — мобильные стили и медиазапросы, подключается после основного файла.
- `js/main.js` — мобильное меню, фильтрация каталога, демонстрационная обработка форм.
- `lighthouse/` — сюда нужно добавить скриншот/отчёт Lighthouse после проверки.

## Адаптивные решения
- Mobile First: базовые стили рассчитаны на узкие экраны.
- Медиазапросы: 600px, 900px, 1200px.
- Навигация на мобильных раскрывается кнопкой с `aria-expanded`.
- Карточки товаров перестраиваются с 2 колонок на телефоне до 4 колонок на широком экране.
- Форма на мобильном отображается в одну колонку, на более широких экранах — в две.
- Изображения используют `max-width: 100%`, `height: auto`; в карточке ноутбука добавлены `srcset` и `sizes`.
- Таблица характеристик помещена в контейнер с горизонтальной прокруткой, чтобы не расширять страницу.

## Доступность
- Добавлена ссылка skip-link для перехода к основному содержимому.
- Используются семантические `header`, `nav`, `main`, `section`, `article`, `footer`.
- На страницах один главный заголовок `h1`.
- Видимый фокус через `:focus-visible`.
- Формы имеют связанные `label`.
- Изображения снабжены alt-текстом.
- Сообщения форм объявлены как `role=status` / `aria-live`.
- ARIA применяется только для состояний меню и сообщений.

## Проверка размеров
Рекомендуется проверить 360px, 430px, 768px, 1024px и 1440px. При проверке нужно убедиться, что горизонтального скролла всей страницы нет; прокрутка допускается только внутри контейнера таблицы.

## Lighthouse
Проверить страницы `index.html`, `catalog.html` и `order.html` в Lighthouse, выбрать Accessibility и сохранить скриншот/отчёт в папку `lighthouse/`. **Отчёт не приложен автоматически — проверку необходимо провести в браузере.**
